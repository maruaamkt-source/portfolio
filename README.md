# Portfólio do Maruã

1. `npm install`
2. `npm run dev` e abra http://localhost:3000
3. Para publicar: suba a pasta no GitHub e importe no Vercel (nenhuma configuração extra).

Arquivos principais:
- `app/page.js`: conteúdo e animação do rei
- `app/globals.css`: estilo
- `public/hero.mp4` e `public/rei.webp`: vídeo do hero e a peça
